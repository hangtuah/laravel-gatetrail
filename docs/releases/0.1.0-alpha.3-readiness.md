# `v0.1.0-alpha.3` release readiness

- Status: **Ready pending external publication steps**
- Reviewed: **2026-10-12**
- Intended release: **first public alpha**

## Release intent

`v0.1.0-alpha.3` makes the existing pre-v1 package available for evaluation
and controlled non-production use. It does not claim stable compatibility,
parity with an application's existing authorization system, or verified
PostgreSQL or SQL Server application-runtime support.

There is no runtime-code difference from the accepted private
`v0.1.0-alpha.2` baseline. Commits after that tag contain documentation,
consumer guidance and internal-pilot acceptance evidence. The pre-v1 public API
boundary remains the one accepted in ADR 0014 and listed in `docs/PUBLIC_API.md`.

## Distribution review

The tracked Git archive contains 689 entries and is approximately 4.6 MB
uncompressed or 1.3 MB as a zip. No tracked `vendor/` directory is present.

Running `composer archive` directly from a development checkout included the
locally installed ignored dependencies and produced an unsuitable archive.
That local result must not be published. GitHub and Packagist distributions
must be built from tracked repository content or another clean checkout.

## External publication checklist

These actions change public external state and require an explicit maintainer
go-ahead. Perform them in order:

- [ ] Confirm the final CI run for the release-preparation commit is green.
- [ ] Change the GitHub repository visibility from private to public.
- [ ] Confirm private vulnerability reporting is available and enabled.
- [ ] Create annotated tag `v0.1.0-alpha.3` on the reviewed commit.
- [ ] Create a GitHub pre-release from that tag and the matching changelog.
- [ ] Submit `https://github.com/hangtuah/laravel-gatetrail` to Packagist.
- [ ] Enable or verify the Packagist GitHub update hook.
- [ ] In a clean consumer application, install the exact release from
  Packagist without a custom VCS repository.
- [ ] Run `gatetrail:install`, the documented vertical slice and the supported
  diagnostic matrix in that clean consumer.
- [ ] Record the GitHub release URL, Packagist URL, CI run and clean-install
  result in the release record.

## Decision

The package is technically ready for a public alpha once the final CI run is
green. Repository visibility, tagging, GitHub release creation and Packagist
submission remain explicit maintainer-controlled actions. This readiness
decision does not complete the stable-release phase or make a `1.0.0`
compatibility promise.
