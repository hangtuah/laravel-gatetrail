# `v0.1.0-alpha.3` release readiness

- Status: **Published and independently installable**
- Reviewed: **2026-10-12**
- Intended release: **first public alpha**

## Release intent

`v0.1.0-alpha.3` makes the existing pre-v1 package available for evaluation
and controlled non-production use. It does not claim stable compatibility,
parity with an application's existing authorization system, or verified
PostgreSQL or SQL Server application-runtime support.

There is no runtime-code difference from the accepted private
`v0.1.0-alpha.2` baseline. Commits after that tag contain documentation,
consumer guidance and internal-pilot acceptance evidence. The pre-v1 public API
boundary remains the one accepted in ADR 0014 and listed in `docs/PUBLIC_API.md`.

## Distribution review

The tracked Git archive contains 689 entries and is approximately 4.6 MB
uncompressed or 1.3 MB as a zip. No tracked `vendor/` directory is present.

Running `composer archive` directly from a development checkout included the
locally installed ignored dependencies and produced an unsuitable archive.
That local result must not be published. GitHub and Packagist distributions
must be built from tracked repository content or another clean checkout.

A new Laravel `13.35.0` application on PHP `8.3.31` installed
`hangtuah/laravel-gatetrail:v0.1.0-alpha.3` as a Packagist dist without a custom

The clean application's public-API vertical slice created a role and permission,

## Documentation corrections in this release

- `README.md` identifies the package as a public alpha and uses the exact
  `0.1.0-alpha.3` Composer constraint.
- `docs/CONSUMER_GUIDE.md` no longer claims that no release exists.
- `docs/PRIVATE_COMPOSER_INSTALLATION.md` is an optional private-mirror or
  private-fork path rather than the primary installation path.
- `CHANGELOG.md` separates `0.1.0-alpha.3` from the next unreleased work.

## Decision

`v0.1.0-alpha.3` is published as GateTrail's first public alpha and is
independently installable from Packagist. This publication does not complete
the stable-release phase or make a `1.0.0` compatibility promise.
